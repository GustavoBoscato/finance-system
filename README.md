This application will be a financial system, this way is used to accountantly. The system allows the management with financial mathematics, therefore, it's managing objects financials.

### Features

--User autentication.
-- Create, read, update and delete expenses.

-- Income percentage management

### Technology/Stack

- Frontend: React.js
- Backend: Node.js + Express
- ORM: Sequelize
- Database: PostgreeSQL
